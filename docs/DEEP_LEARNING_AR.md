# التعلّم العميق في مشروع AURA VISION

يجمع هذا الملف كل ما يخص التعلم العميق في المشروع: النماذج المستخدمة، والبيانات، والخوارزمية، والنتائج، وأماكن الملفات، وأوامر التشغيل.

## 1. النماذج العصبية في النظام

| النموذج | مصدره | ماذا يفعل |
|---|---|---|
| **AURA hand-pose network** | **دُرِّب في هذا المشروع** | يصنّف وضعية اليد إلى 8 فئات من نقاطها الـ 21 |
| GestureRecognizer (MediaPipe) | نموذج جاهز من Google | يكتشف اليد ويستخرج 21 نقطة (landmarks) ويعطي تصنيفاً أولياً |
| FaceLandmarker (MediaPipe) | نموذج جاهز من Google | 478 نقطة للوجه و52 قيمة لتعابيره (blendshapes) |

خط المعالجة لكل إطار من الكاميرا:

```
إطار الكاميرا ─► GestureRecognizer (CNN) ─► 21 نقطة لليد ─► poseVector (63 رقماً)
                                                            │
                                                            ▼
                                             شبكة AURA (MLP) ─► softmax على 8 فئات
                                                            │
                         دمج (fusion) مع تصنيف MediaPipe ومسافة القرص ─► أمر الروبوت
```

كل شيء يعمل محلياً على الجهاز: لا إنترنت، ولا مفتاح API، ولا تُرسل صور.

## 3. الخوارزمية

### المدخل: poseVector (63 رقماً)
- النقاط الـ 21 لليد، كل منها (x, y, z).
- تُطرح نقطة المعصم من كل النقاط، فيصبح الموضع في الصورة غير مهم.
- يُقسم الناتج على حجم الكف (متوسط المسافة من المعصم إلى قواعد السبابة والوسطى والخنصر)، فيصبح البعد عن الكاميرا غير مهم.
- الدالة نفسها مكتوبة في Python وJavaScript، ومختبرة لتعطي نفس الأرقام.

### الشبكة: Multi-Layer Perceptron
```
63 مدخلاً ─► Dense 128 + ReLU ─► Dense 64 + ReLU ─► Dense 8 ─► Softmax
```
- عدد المعاملات: **16,968**.
- مكتوبة من الصفر بـ **NumPy**: الانتشار الأمامي، والانتشار العكسي (backpropagation)، ومُحسِّن Adam. لا مكتبة جاهزة، فكل سطر قابل للشرح.

### التدريب
| | |
|---|---|
| دالة الخسارة | Cross-entropy موزونة بالفئات، لأن الفئات غير متوازنة (OTHER = 2,199 مقابل 147 لـ THREE) |
| المُحسِّن | Adam (β1 = 0.9، β2 = 0.999)، معدل تعلم 0.002 مع جدول cosine |
| التنظيم (regularization) | L2 = 1e-4 |
| حجم الدفعة | 256، و80 حقبة (epochs) |
| زيادة البيانات (augmentation) | 4 نسخ إضافية لكل عيّنة: قلب أفقي (يد يمنى ↔ يسرى)، ودوران ±25°، وضجيج على النقاط (σ = 0.03) |
| التقسيم | 80% تدريب (4,245) / 20% تحقق (1,057)، مُطبّق (stratified) لكل فئة |
| اختيار النموذج | الحقبة ذات أقل خسارة تحقق (الحقبة 4) |
| وقت التدريب | 18 ثانية على المعالج (CPU) |

### الدمج (fusion) مع باقي النظام
1. **القرص (PINCH):** من مسافة الإبهام والسبابة.
2. **ثلاثة أصابع (ركض):** من الشبكة إذا كانت ثقتها ≥ 0.7، لأن نموذج MediaPipe لا يملك هذه الفئة.
3. **تصنيف MediaPipe** إذا كان واثقاً. القبضة (القفل) تأتي منه فقط، للأمان.
4. **إذا لم يكن MediaPipe واثقاً:** الشبكة تقرر. وإذا قالت OTHER بثقة، يُرفض الأمر.

### دقة الشبكة على بيانات التحقق: **95.9%**

| الفئة | Precision | Recall |
|---|---|---|
| OPEN_PALM | 0.95 | 0.99 |
| FIST | 0.98 | 0.99 |
| POINT | 0.93 | 0.93 |
| TWO_FINGERS | 0.98 | 0.97 |
| THREE_FINGERS | 0.91 | 1.00 |
| THUMB_UP | 0.75 | 1.00 |
| THUMB_DOWN | 0.96 | 0.84 |
| OTHER | 0.98 | 0.95 |

### أثر الشبكة على قرارات النظام كله (نفس صور التحقق)

| | قواعد فقط | MediaPipe + قواعد (قبل) | **مع الشبكة (الآن)** |
|---|---|---|---|
| الدقة الكلية | 75.7% | 78.9% | **90.7%** |
| التعرف على الركض (3 أصابع) | 82.8% | 82.8% | **100%** |
| التعرف على الكف المفتوح | 99.4% | 49.4% | 98.9% |
| أمر خاطئ على وضعية ليست أمراً | 47.4% | 20.3% | **14.4%** |

### الاختبار المباشر بالكاميرا
- **محرك المتصفح:** المشي 0.7 م/ث ✅، والركض 1.6 م/ث ✅، والقرفصاء (10 مرات) ✅، والدوران حتى 790°/ث ✅، والقفل L ✅.
- **محرك Python:** المشي ✅، والركض ✅، والدوران حتى 880°/ث ✅، والقفل ✅. المعالجة 15 إطاراً/ث.
- **الابتسامة:** تعمل بعد إضافة المعايرة الشخصية (طرح مستوى الوجه الطبيعي لكل شخص).
- **الحزن:** اكتُشف مرة واحدة.
- **المفاجأة:** لم تُكتشف في الاختبار المباشر.

### حدود يجب ذكرها بصراحة
- نسخة البيانات المستخدمة لا تحدد هوية الأشخاص، فقد يظهر الشخص نفسه في التدريب والتحقق. الأرقام إذن متفائلة قليلاً لمستخدم جديد.
- فئة الركض والإبهامين فيها نحو 150 صورة فقط لكل فئة.
- أكثر الأخطاء المتبقية:
  - إشارة OK، وهي فعلاً تلامس الإبهام والسبابة، فتُقرأ قرصاً.
  - إشارة "اصمت" (السبابة على الشفاه)، ويقرؤها MediaPipe إشارةً بالسبابة.

## 6. أوامر التنفيذ (من مجلد `D:\Ai_Cv`)

### تشغيل النظام
```powershell
cd D:\Ai_Cv
npm run dev
```
افتح **http://127.0.0.1:5173** في المتصفح، واضغط **Start camera**، واسمح بالكاميرا.

أو بمحرك Python (المعالجة في Python والعرض في المتصفح):
```powershell
npm run dev:python
```
ثم افتح **http://127.0.0.1:5173/?engine=python**.

للإيقاف: اضغط `Ctrl + C` في نافذة الطرفية.

### إعادة التدريب أمام الدكتور (≈ 20 ثانية)
```powershell
.venv\Scripts\python.exe -I training\train_handpose.py --three three
```
يطبع الخسارة والدقة كل 10 حقب، ثم يحفظ الأوزان والتقرير.

### خطوات البيانات كاملة (إن لزم)
```powershell
.venv\Scripts\python.exe -I training\fetch_dataset.py --row-groups 2   # تنزيل (يحتاج إنترنت)
.venv\Scripts\python.exe -I training\extract_landmarks.py              # استخراج النقاط (بضع دقائق)
.venv\Scripts\python.exe -I training\show_samples.py                   # صور للعرض في data\hagrid\samples
```
